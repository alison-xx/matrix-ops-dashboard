# 内容制作与发布执行分工

使用者可将选定平台的内容制作与发布执行分开：制作端输出稳定ID、建议时间/时区、标题正文、话题、视频/HTML、封面配图、来源及质检、已有任务和URL。计划、制作完成、交付、提交、公开分别记状态。

在账号配置中设置 `publish_via: external_agent`，本调度器会拦截这些账号的自动提交；其余平台保持原通道。执行方使用自己的获授权工具，发布前核实平台查重与原单状态；不通过交接绕过工具访问限制，不自动转发聊天指令。

既有原生定时不自动撤销或重投；结果不明先核实。回执按稳定ID回填任务ID、实际时间、公开URL与证据。自动任务提示词、入口手册与报告口径须一起更新；不能只修改聊天约定。


## 每日提前交付

按发布窗口倒排制作截止，给执行方留出检查与平台定时的提前量。前一天建立次日计划并准备非时效素材，新闻事实在当天复核。早、午、晚生产任务负责各自窗口，监测任务补查缺口；其他平台原自动发布保持。

当日交接目录包含计划、manifest、预览页和素材压缩包。每条独立目录存标题正文话题、完整媒体/封面/有序配图、事实来源、审阅及音画质检。manifest使用稳定ID、时区、发布时间、版本、SHA256、状态与已有原单。

素材先落盘并通过质检，再将单条状态更新为ready_for_handoff；不能只凭压缩包存在认定可发。执行方领取或提交后不静默覆盖版本。制作方读取并增量合并回执，不覆盖执行方拥有的记录。超时明确记录缺口和下一步，后续任务补齐；报告区分按时交付、已提交和有证据公开。
