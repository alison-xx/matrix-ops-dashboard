# 配音发音与发布格式验收

配音前运行 `python scripts/pronunciation.py spec.json`。仅对已确认含义的词组作口播专用改写，例如国行（guó háng）改为中国大陆版本；字幕与原稿不改。不要逐字替换多音字，也不要假设引擎支持拼音或 SSML。

音频缓存包含发音规则版本、口播、音色、语速和指令，规则变化必须重合成。`audio_qc.py` 使用实际口播文字对照，并输出 pronunciation_review。ASR 同一汉字不能区分不同读音；发布前完整听检，复核多音词、专名、缩写、数字单位，把具体词、读音和验收结果写入 review.md；未听检不得声称通过。

发布后读取作品正文，检查 HTML 或转义标签是否被字面显示。若源载荷为纯文本而线上出现标签，保留证据并隔离故障通道，不凭推测归责。支持编辑时修改原作品并核对同一公开链接，不自动删重发。

临时使用网页时，将自己账号配置的 publish_via 设置为 web，ops.submit 会阻止继续经 CLI 提交。通道恢复需平台结果证明，配置自检不等于恢复。已公开音轨无替换能力时如实记录，不把本地修正称为线上修复。
