# 公开导出范围与隐私边界

包含：看板源码、虚构示例、运营工具的脱敏源码、通用审核和素材规则、配置模板、技能来源及项目自有的编排技能。

排除：真实 config、.env、state、days、reports、登录二维码、Cookie、Token、SSH 私钥、邮箱地址、本机用户名和路径、平台账号 ID、真实收入和运营台账、私人经历、交接记录、个人照片/头像/克隆音色、已购素材、对标文章全文、浏览器记录和本机定时任务配置。

原系统品牌与第二账号标识在公开版统一为 creator / office。example.com、demo-account-id 等是占位数据。第三方作者的公开署名、上游链接和字体版权声明保留，用于来源与许可识别。

提交前运行 `python3 scripts/check_public_tree.py`，再审查 git diff。扫描检查常见凭据格式、真实数据路径、个人目录和二进制白名单；它不替代人工审查，也不保证发现所有未知隐私。扫描只打印文件与类别，不回显凭据。示例数据启动时在本机生成，受 .gitignore 保护。

## 明确允许公开的服务入口

按项目维护者要求，文档保留 [灵策 Web](https://web.lynxce.cn/) 与 [灵策AI热点](https://aihot.lynxce.cn/) 的公开品牌和入口，用于注册引导及工作流接入。这不包含个人账号、登录凭据、真实台账或私人站点配置；代码中的私有集成仍使用示例配置。
