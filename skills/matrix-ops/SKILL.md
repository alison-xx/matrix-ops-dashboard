# 矩阵运营编排

先读工作区 AGENTS.md 与运营手册入口、当前计划；确认本轮任务和使用者授权范围。不从这个公开模板推断已获发帖、发邮件或付费授权。

内容路径：来源核实 → human-writing 起草 → 平台技能 → humanizer-zh 改稿 → 素材制作 → platform-content-review → lint → 占位与提交 → 平台回读 → 台账 → 数据复盘。

- 对来源、实测、个人经历和收入，只使用可核验材料。
- 同话题同平台去重；uncertain 状态先回读，不盲目重发。
- 需要扫码或验证码时交还用户，复用已有有效会话。
- review.md 记录文本和素材版本、风险处理与逐平台结论。
- scheduled、API success 与公开可见分开记；完成报告附真实证据。
- 不把真实配置、台账和媒体导入公开 Git 仓库。

操作细节见 docs/operations.md、docs/skills.md 及运营手册中的公开参考流程。依赖技能不可用时明确缺失，不伪造已执行记录。
