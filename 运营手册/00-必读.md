# 公开版运营入口

先读 ../docs/operations.md、技能地图.md、发布前违禁词检查.md。账号、预算、发布授权、配额与人设由使用者维护，不继承上游工作区的私人配置。

开工：明确任务 → 读取当前运营计划 → 核对未完成条目和平台状态 → 执行质量与用词检查 → 在自身授权范围内执行。
收工：记实际完成、证据、未完成项和后续动作。定时提示词只引用此入口与任务名。

所有正式发布前必须核实来源、逐平台复核全部最终文本和可读素材，记录 review.md。提交成功和实际公开分开记。真实数据保存在本机被忽略的 state、days、reports 中。

研究和借鉴领域创作者时，读 [创作者研究流程](../docs/creator-research.md)。区分候选池与权威排名、元数据与完整脚本；参考结构后用自有材料重建，并留来源与验证记录。

音频与正文格式验收读 [发音和格式检查](../docs/pronunciation-and-format.md)：发音规则改动要刷新音频缓存，ASR不能替代多音词听检，发布后核对纯文本没有被展示成HTML。
