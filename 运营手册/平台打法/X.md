# X 平台接入参考

看板支持 x / twitter / 推特 别名与X标识；使用者自行配置账号。本文件不包含维护者的真实账号、排期或互动记录。

## 内容与发布

从有出处的资讯或自己的真实实测出发，正文给一个清楚的判断，再附必要来源。长内容拆分时，每条仍要能读懂前后关系；话题和@对象与内容有关，不为扩大触达批量提及陌生人。

发布前核对完整正文、话题、@对象及图片文字。content-compliance-checker 没有X专用词库，使用通用候选检查，再结合语境与当前官方规则；不要把其他平台的词表当成X专用规则。

使用自己的账号和已获授权的发布通道。发布或定时后保留回执，实际公开后再记录作品链接；结果不确定先回读，避免重复提交。

## 互动与数据

engage.py 中的上限是可配置的示例，不能替代当前平台规则和使用者授权。区分手动会话、无人值守任务和API能力，不因其他平台可以自动互动就照搬。

采集作品的展示、互动与关注数据时记录统计窗口、采集时间与字段来源。缺失数据不要填0，展示量不等于人数。按 [数据回流](../数据回流.md) 接回本地看板。
