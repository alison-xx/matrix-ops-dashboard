# 技能地图（每个平台、每个环节用哪个 skill）


依据：`docs/skills.md`（搜了 60 多个关键词，候选审查、纸面试用、安全审查的记录都在里面），以及之前两轮排版和去 AI 味的评估。

**原则**：主线不变，仍然是 `human-writing` 起草 → `humanizer-zh` 定稿 → 逐平台违禁词终检 → lint（00-必读 2.2.1、2.2.8）。新技能按地图插入检查点；已安装技能通过宿主技能入口调用，无专用入口时读取对应 SKILL.md 执行。新技能里和我们手册冲突的部分一律关掉（见第 3 节）。

**选题新增入口（10-17）**：热点雷达先按 `对标蒸馏.md` 运行 `creator_watch.py` 抓主要讲AI博主新作，再核事实、去重、更新原选题库和当天 `creator-watch/content-plan.md`。各班制作前读这个计划；`opc-short-video-review` 审查借鉴结构后的承诺与证据，不把作者流量当本号已验证效果。

**所有平台统一增加发布前检查**：`content-compliance-checker`（已安装于 `/path/to/workspace`）+ 当前平台手册 + 素材逐字复核。适用于下表所有行，也包括快手、公众号贴图及两个抖音号；操作和证据格式见 `发布前违禁词检查.md`，候选来源见 `docs/skills.md`。它是提示词技能，不是自动扫描服务；社区词表不是官方禁词清单。

## 2. 新技能怎么调（照抄提示词）

- **xy-opener**（视频 hook）：输入 hook + 第 2、3 个场景的口播、栏目、hook_type。提示词写明「拍法是有画面配合的动效视频；一口气全出，不要分段停下来问我」「方法 B 只能用 test/ 目录或来源链接里的真事实」「不要运行 atoms-search.py」。要查案例就只查本地：`XY_ATOMS=$HOME/.claude/skills/xy-opener/references/atoms.jsonl python3 -I $HOME/.claude/skills/xy-opener/scripts/atoms-search.py "关键词" -k 5`。从它的 Top 3 里按 `批次执行.md` 2.4 节硬规则挑一条，诊断结论记进 review.md。
- **xy-script-glue**（2 分钟以上视频的衔接）：「每个 scene 算一段，拍法选有画面配合，一口气出完报告和标记式改稿」。🔴 必改；🟡 改不改在 review.md 写理由；改完的句子写回 spec。
- **zhihu-answer-master**（知乎）：写稿前只要三样：问题类型对应的开头类型、前 3 条高赞和我们差在哪（内置浏览器看）、人设口径（只能用 `人设与口吻.md` 的真实要素，否则用拆解者口径）。发布前用它的规则终检：前 50 字截断后仍有判断、有一句局限性声明、写两条互动预案记进 `zhihu-answers.md` 备注列。
- **wechat-article-craft**（公众号）：只用它的反方补搜、独特性检查、标题候选和五扫审校；正文由 `human-writing` 起草（00-必读 2.2.1）。读者设定「职场里用 AI 干活的普通人」，风格按 `平台打法/公众号.md` 现行对标。它的审校摘要和待核验项写进 review.md，不进正文。
- **dbs-xhs-title**（小红书标题，10-16 装）：给它话题、读者、这条能带走什么，让它从公式库挑 2–3 个公式各出 1 个标题并写公式编号；再按 `平台打法/小红书.md` 第 2 节改：搜索词放第一个词、≤20 字、不用 lint 禁词（震惊、保姆级、建议收藏这类）。公式编号写进 review.md，方便日报按公式类型看数据。
- **opc-short-video-review**：发布前对 18:00 系列做 Script Audit，只取「最大瓶颈」和「发布假设」各一句写进 review.md；日报用 Data Review 模式做漏斗诊断（先过 `运营计划.md` 的样本量门槛）。经验写进 `运营计划.md`，不写进技能目录的 case-library。

## 3. 关掉的部分（和手册冲突）

- zhihu-answer-master：「金句」模板（和 human-writing 禁翻案句冲突）、抖机灵模式、1500–4000 字默认篇幅（按知乎.md 600–1200 字）、发布时间建议（按排期）。
- xy-opener / xy-script-glue：逐段停下来问人的交互流程（定时任务没人回答）。
- wechat-article-craft：默认 3500 字、强人设风格、Phase 6 发布包、封面、ImageGen、`wechat-formatter.py`（排版用我们自己的）。
- **已停用**（10-16）：`china-video-video-editing`、`post-production-guide`（付费版引流空壳，正文自称不含方法论）已移到 `~/.claude/skills-disabled/`。


## 4. 维护

- 这几个技能**不要跑 `skillhub upgrade` 自动升级**：升级时先下载到临时目录 diff 审一遍再覆盖。查本地文件有没有被改：`~/.local/bin/skillhub --skip-self-upgrade --dir ~/.claude/skills verify <slug> --namespace <作者>`。
- 周进化每周按这些关键词在 SkillHub 搜一次新技能：抖音、视频号、B站、小红书、微博、知乎、公众号、口播稿、开头、标题、封面、剪辑、字幕、复盘、涨粉。有明显增量的先下载到临时目录，完整读 SKILL.md 和脚本做安全审查（读密钥/cookie、往陌生域名发数据、下载远程代码执行、`rm -rf`、混淆、要付费 key），通过才装，并更新本文件和变更日志。
