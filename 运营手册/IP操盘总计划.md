# 个人影响力与课程运营框架

本文件为通用方法模板，使用者自行确定目标、预算、平台授权和课程商业条件。生产排期与实际发布台账分开，计划数不计公开数。

## 定位

分别写清每个账号的目标观众、具体任务、持续承诺、真实证据和内容边界。个人实践账号展示判断与过程；办公教学账号展示完整成果与练习。产品是有用时出现的案例，不替代观众需求。

## 阶段

- 前两周：统一同源数据基线，收集真实问题，完成3份样课包。
- 首月：形成核心课程单元设计，用可比作品和学习反馈选持续栏目。
- 次月：准备小范围试教材料，记录作业结果和答疑成本。
- 第三月：评估完整课程、服务容量和真实付费意向，再决定商业方案。

这些是内部工作目标，不是增长或收入保证。样本不足应延长观察。

## 单课资产

每课保存：任务及先修要求、可公开输入、真实演示、可打开成品、独立练习、验收标准。首段先给成果，中段讲如何完成，必要修正服务于交付。课程索引引用原作品ID，不创建第二套发布台账。

可按信息整理、表格分析、表达交付、流程复用安排学习顺序；每天的案例和进阶不等于重新售卖同一课程。

## 数据与决策

分别记录同源粉丝净增、真实问题、练习提交与达标数、课程明确意向。无分母不报完成率；作者首评不算需求；浏览不等于购买。跨平台账号不能合并成独立受众人数。先核数据时效、作品ID与可比样本，再调整长期结构。

## 承接

免费内容 → 完整样课 → 学习反馈 → 课程候选 → 试教 → 付费方案。新招生、收集入口、价格、退款和支持承诺按使用者实际授权执行。实收减退款、平台费、工具及交付成本后再讨论利润。

## 执行

复用生产、回收、日报、周复盘任务。每条内容标记受众、结果、证据、平台独立角度和观察指标。按实际合格产能排队，质量失败记录空缺，不补量伪装完成。每周复查假设，不用单条爆款重写定位。
