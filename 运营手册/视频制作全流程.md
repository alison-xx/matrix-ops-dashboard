# 内容先行的视频制作流程

先确定受众、问题、结论、证据与可交付成果，再拆脚本、寻找素材、提取选段、剪辑和验收。

1. 内容：企业实操先跑通任务，核验输入输出；区分实测、计划与情景演绎。
2. 分镜：每镜记录口播、成片起止、画面目的、素材ID、源入出点、字幕、转场和配乐提示。以最终旁白校正时间。
3. 素材：优先真实录屏和结果，其次使用权明确的素材，生成视频补足必要的情景镜头。保留来源、使用范围、hash与版本；不生成伪界面和伪数据充当证据。
4. 剪映：创建独立可编辑工程，画面、旁白、BGM、音效、字幕分轨；按表达需求使用关键帧放大、分屏、遮罩、标注、转场和色彩统一。功能需在实际工程验证，不为炫技堆效果。
5. 每条视频配BGM：记录源区间、目标区间、增益和淡入淡出，按乐句剪接；讲话压低，句间不突然回弹，结束自然收束。已有混音不能再叠一层音乐。音量百分比不等于听感合格。
6. API：按缺失镜头调用当前已配置模型，保留任务ID；结果未知续查，不双投。实际价格、模式与可用性调用前核验。
7. 验收：工程打开、素材在线、轨道与时长正确；实际导出后对最终文件重新音画QC、完整播放和试听。分别记录程序检查、模型听检、人工试听的实际范围，源版QC不能代替终版验收。

每条交付：内容稿、分镜表、素材清单、音乐cue表、可编辑工程、最终成片、字幕、封面、验收记录。制作完成、交接、平台提交和公开分开记账。
