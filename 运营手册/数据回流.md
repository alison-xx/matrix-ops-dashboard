# 数据回流（2026-10-16 起）

蚁小二的作品数据同步慢（10-16 凌晨还看不到 10-15 晚上的作品），复盘没东西可看。现在直接从各平台创作者中心取数：内置浏览器都已登录，数据比蚁小二全（抖音有完播率、2 秒跳出、涨粉、主页访问）。

## 1. 什么时候采

- 每天 2 次：12:40 那轮互动开始前、22:40 那轮互动开始前（日报 23:00 要用）。
- 热点快反发出 2 小时后，可以单独采一次抖音/视频号看开头留存。

## 2. 怎么采（每个平台 1 分钟）

内置浏览器新开标签页或用已有标签页，打开对应页面 → `javascript_tool` 执行脚本文件的全部内容 → 返回的 JSON 字符串**原样**存成 `days/<今天>/metrics/<平台>-<账号>.json` → 入库：

```bash
.venv/bin/python scripts/metrics.py ingest <平台> <账号> days/<今天>/metrics/<平台>-<账号>.json
```

|平台|打开的页面|脚本|备注|
|---|---|---|---|
|抖音（示例作者）|creator.douyin.com/creator-micro/content/manage|scripts/collectors/douyin.js|字段最全：完播、2 秒跳出、5 秒完播、均看时长、涨粉、主页访问|
|抖音（Office）|同上，但要在蚁小二「打开创作中心」的窗口里执行（内置浏览器登录的是示例作者）|同上|账号名写 Office|
|小红书|creator.xiaohongshu.com/new/note-manager|scripts/collectors/xhs.js|接口要页面签名，脚本会点「已发布/全部」让页面自己请求再截取|
|微博|weibo.com（任意页）|scripts/collectors/weibo.js|reads_count 是阅读数，只有自己能看到|
|视频号|channels.weixin.qq.com/platform/post/list|scripts/collectors/channels.js|读卡片：播放/喜欢/评论/转发/推荐；没登录就跳过并提醒用户扫码|
|知乎|www.zhihu.com/creator|scripts/collectors/zhihu.js|回答、文章、想法都在一起|
|公众号|mp.weixin.qq.com 后台（会话几小时就过期）|待做|过期就跳过|

脚本返回 `{"error": ...}` 时按提示处理，不要硬改脚本凑数。

## 3. 怎么看

```bash
.venv/bin/python scripts/metrics.py report 7      # 写到 days/<今天>/metrics/report.md
```

报告里有：每条作品最新数据、按栏目/时段/时长汇总、逐条诊断（只列能改的动作）。日报（daily_report.py）会自动把 report.md 附进去。

## 4. 看完要做的事（写进当天复盘）

- 2 秒跳出 ≥35% 或 5 秒完播 <50%：下一条视频的开头按 `批次执行.md` 的留存结构重写。
- 同一条内容在不同平台差 10 倍以上：说明是平台分发问题不是内容问题，记进 `复盘要点.md`，调整各平台发布配比。
- 播放 <50 的作品不下结论，等 24 小时后的快照。
- 每周日：按栏目/时段汇总调整下周排期（内容总纲第 9 节）。
